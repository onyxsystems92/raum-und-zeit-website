# Raum & Zeit Website

Private first-draft website for **Raum und Zeit Physiotherapie · Sarah Weber · Düsseldorf-Oberkassel**.

## Status

Presentation-ready prototype / first client implementation for Visibility Intelligence.

## Run locally

This project is intentionally static and dependency-free.

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

You can also open `index.html` directly in a browser; a local server is preferred for consistent behavior.

## Deployment

The site can be deployed as a static project to Cloudflare Pages, Vercel, Netlify, GitHub Pages, or any static host. No build command is required.
